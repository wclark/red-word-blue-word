    04 Name the idea

    A big idea made from small rules

    This is a bigram model: it remembers two-word patterns, not meanings.

    1

    Break it into pairs

    Every red word is followed by one blue word from the source.

    2

    Let X mark the edges

    X → word starts a sentence. word → X ends one.

    3

    Patterns steer chance

    Pairs that appeared more often have more cards, so they are more likely to be drawn.

    Questions for curious humans

    • Which parts sound like the source—and which parts do not?
    • What changes when you add a very different kind of writing?
    • Who should get credit for a sentence generated from someone else's words?
